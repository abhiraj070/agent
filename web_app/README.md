# Web App

A Next.js application.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Included Shape

- edit site code under `app/`

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the Next.js production build
- `npm test`: build the starter and verify its rendered loading skeleton
